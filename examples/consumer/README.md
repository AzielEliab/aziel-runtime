# Minimal public consumer skeleton

Author: **Aziel Eliab** only.

This folder is a **skeleton**, not an adoption claim and not an independently validated client.

Open `index.html` against a running runtime origin (default `https://aziel-runtime.vibelock.workers.dev`). It fetches `GET /v1/software` and lists Softwares-tab cards. It does not enable mesh, SMTP, or remain-OFF items.

Gaps 21–22 (deanonymize / mesh default) stay assessed, not implemented.

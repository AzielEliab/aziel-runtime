Security features
SEC-FEAT-1.0 · runtime 1.6.13 + public repos · 2026-09-06 · Aziel Eliab

Inventory of controls that shrink the surface. Not a guarantee. Not a new product.

1. Door / kernel — live
- Hashed FragGate registry. Unknown slug → FG-HALLUC-TOOL.
- 124 stub ops: named refuse, not silent success.
- DecisionGATE pre-exec: five gates → PASS / REVISE / BLOCK.
- Thin MCP tools/list. Proxy /p/{slug}/{op} is not exec.
- runtime_run is internal. Empty User-Agent 403s on Workers.
- GET /v1/mesh never enables. No Node Gate on public faces.
- Refuse is written to the ledger.

2. Credentials, identity, vault — live
- No password fields. No browser-login bots. No stored cookie jars.
- Tokens in env / keychain only. Ledger stores token_present.
- AZBOT_PUBLISH=1 before any network post. Queue default.
- Public identity Aziel Eliab only. Slingshot Prep is local strip + hash, not an upload proxy.
- ARK hosted never unlocks. Stub: unlock / encrypt / scorch / wipe.
- EmbryoLock local-not-hosted. Not a FragGate engine.

3. Fabric / phoenix — live in qnm-node, topology specified
- Loopback API. APG on every ingress. Poison refused, not interpreted.
- Tamper isolates. ID spent. Tethers cut. No account resurrection.
- PHOENIX-LOCK waits locally. No controller hunt. No auto-heal onto a spent ID.
- Hop-max + seen-hash drop loops.
- Specified: cell 25, two rotating bridges, process ON / public rollup OFF.

4. Stub refuses that cut surface — live
- azos: exec
- ark: unlock, encrypt, scorch, wipe
- azmail: smtp, send, login, harvest, deanonymize, credential_capture
- azieltether: vpn, arm, mesh-join
- miragegrid: mesh, vpn-hop, hop, tunnel
- whistlelock: send, mail, release
- veillock: inject, intercept, facetime
- embryolock: entire engine (not hosted)

5. Book, browser, publish — live law
- Hash questions and acts. Do not chain answers.
- ZionPattern cap 75%. Missing run stays unblended. Jeeves cannot change scores.
- Doe lead ≠ ID. Heat ≠ presence. No live tracking.
- AZBrowser: cite, refuse harvest, no invented visits. AZNet does not host payloads.
- Held publish does not flush across phoenix without a new act (NODE-OPS specified).
- Local HTTP: nosniff, DENY frames, no-referrer, camera/mic/geo off, tight CSP.

6. Not a security feature
- Mesh-on from a public page.
- A Node Gate so you can watch the cell.
- MirageGrid as a VPN.
- Hosted vault unlock.
- Auto-heal.
- The word bulletproof as a guarantee.

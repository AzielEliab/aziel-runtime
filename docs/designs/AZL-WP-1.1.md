 5. Ledger
 Canonical JSON. hash = SHA-256({prev, kind, profile, question, payload, utc}). Genesis prev = 64 zeros. JSONL. Kinds:
 genesis, question, act, ask, call, queue, hold, refuse, verify, seal, isolate, rotate, phoenix, assign.
 Payload may: slug, op, input, verdict, why, http, text_sha256, envelope_sha256, engine_digest, token_present, mesh_id,
 cell_id, bridge_ids. Payload must not: model_sentence, password, token_body, cookie, answer_as_object.
 AI cite rule: record.hash + kind + question + payload_sha256. Chain is not ciphertext. Encryption is a local envelope.
